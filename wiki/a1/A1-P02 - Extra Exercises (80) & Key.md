# A1-P02 — Extra Exercises (80) & Key

> Level **A1** · practice

Cover the right-hand answers and try each set aloud. 16 sets, 80 items. The last column gives the rule.

| **Set**                           | **Question → answer**                                                                                                                                                                                                                                                                                                              | **Rule**                                                          |
|-----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------|
| **E1 · Plurals**                  | 1\. il libro → → i libri / 2. la casa → → le case / 3. l'amico → → gli amici / 4. il caffè → → i caffè / 5. la città → → le città / 6. il lago → → i laghi / 7. la mano → → le mani / 8. l'uomo → → gli uomini                                                                                                                     | caffè and città don't change; lago → laghi keeps the hard g.      |
| **E2 · Articles**                 | 1\. \_\_\_ zaino (the) → lo / 2. \_\_\_ studentessa (a) → una / 3. \_\_\_ amiche (the) → le / 4. \_\_\_ aeroporto (the) → l' / 5. \_\_\_ ospedale (a) → un / 6. \_\_\_ psicologo (the) → lo                                                                                                                                        | lo/uno before s+consonant, z, gn, ps; l'/un before vowels (masc). |
| **E3 · Agreement**                | 1\. una ragazza (alto) → alta / 2. i bambini (felice) → felici / 3. le macchine (nuovo) → nuove / 4. un caffè (buono) → un \_\_\_ caffè → buon / 5. una casa (bello) → una \_\_\_ casa → bella                                                                                                                                     | Before a noun buono → buon; bello follows the article's pattern.  |
| **E4 · Present tense**            | 1\. Io (comprare) il pane. → compro / 2. Noi (leggere) il giornale. → leggiamo / 3. Loro (dormire) fino a tardi. → dormono / 4. Lei (capire) tutto. → capisce / 5. Voi (finire) alle sei. → finite / 6. Tu (preferire) il tè. → preferisci                                                                                         | capire / finire / preferire are -isc- verbs; dormire isn't.       |
| **E5 · Irregular verbs**          | 1\. Io (venire) da Milano. → vengo / 2. Tu (uscire) stasera? → esci / 3. Noi (stare) bene. → stiamo / 4. Loro (bere) acqua. → bevono / 5. Lui (dire) la verità. → dice / 6. Voi (dare) il libro a Marco. → date                                                                                                                    | Memorise the table in A1+.4.                                      |
| **E6 · Modals**                   | 1\. Io (potere) \_\_\_ entrare? → posso / 2. Noi (dovere) \_\_\_ studiare. → dobbiamo / 3. Tu (volere) \_\_\_ un caffè? → vuoi / 4. Loro (sapere) \_\_\_ nuotare. → sanno / 5. Lei (potere) \_\_\_ aiutarmi? → può                                                                                                                 | Modal + infinitive; the infinitive does not change.               |
| **E7 · C'è / ci sono**            | 1\. \_\_\_ una farmacia qui vicino? → C'è / 2. \_\_\_ due bagni in albergo. → Ci sono / 3. Non \_\_\_ nessuno. → c'è / 4. \_\_\_ molti turisti a Roma. → Ci sono                                                                                                                                                                   | Singular → c'è, plural → ci sono.                                 |
| **E8 · Reflexives**               | 1\. Io (svegliarsi) alle sette. → mi sveglio / 2. Tu (alzarsi) presto? → ti alzi / 3. Lei (vestirsi) in fretta. → si veste / 4. Noi (divertirsi) molto. → ci divertiamo / 5. Loro (chiamarsi) Marco e Luca. → si chiamano                                                                                                          | Reflexive pronoun before the verb.                                |
| **E9 · Numbers**                  | 1\. 21 → ventuno / 2. 38 → trentotto / 3. 99 → novantanove / 4. 150 → centocinquanta / 5. 2026 → duemilaventisei / 6. 3rd (f.) → terza                                                                                                                                                                                             | Drop the final vowel before uno/otto (ventotto).                  |
| **E10 · Time & dates**            | 1\. 1:00 → È l'una / 2. 4:15 → Sono le quattro e un quarto / 3. 5:45 → Sono le sei meno un quarto / 4. 12:00 → È mezzogiorno / 5. 9 October → il nove ottobre / 6. 1 May → il primo maggio                                                                                                                                         | 5:45 = sei meno un quarto (the next hour minus a quarter).        |
| **E11 · Prepositions**            | 1\. Vado \_\_\_ Roma. → a / 2. Vivo \_\_\_ Italia. → in / 3. Vengo \_\_\_ Milano. → da / 4. Vado \_\_\_ dottore. → dal (da + il) / 5. Il libro è \_\_\_ tavolo. → sul (su + il) / 6. Esco \_\_\_ i miei amici. → con                                                                                                               | Cities → a; countries → in; people's place → da.                  |
| **E12 · Prepositions + articles** | 1\. Vado (a + il) \_\_\_ cinema. → al / 2. Torno (da + la) \_\_\_ Francia. → dalla / 3. Il libro (di + il) \_\_\_ professore. → del / 4. Siamo (in + la) \_\_\_ stazione. → nella / 5. I fiori (su + i) \_\_\_ tavoli. → sui                                                                                                       | See table 1.8.                                                   |
| **E13 · Negation**                | 1\. Make negative: Capisco tutto. → Non capisco tutto. / 2. Make negative: Vedo qualcuno. → Non vedo nessuno. / 3. Make negative: Mangio sempre carne. → Non mangio mai carne. / 4. Make negative: Ho ancora fame. → Non ho più fame.                                                                                              | qualcuno → nessuno · sempre → mai · ancora → più.                 |
| **E14 · Imperative**              | 1\. (Lei, girare) \_\_\_ a destra. → Giri / 2. (tu, andare) \_\_\_ dritto. → Vai / 3. (Lei, scusare) \_\_\_, dov'è il bar? → Scusi / 4. (voi, prendere) \_\_\_ l'autobus. → Prendete / 5. (tu, attraversare) \_\_\_ la piazza. → Attraversa                                                                                        | Lei uses the 'wrong' ending: -i for -are verbs.                   |
| **E15 · Translate to Italian**    | 1\. I'd like a table for two. → Vorrei un tavolo per due. / 2. How much does it cost? → Quanto costa? / 3. I don't like fish. → Non mi piace il pesce. / 4. We have a big family. → Abbiamo una famiglia numerosa (grande). / 5. What time is it? → Che ore sono? / Che ora è? / 6. Where do you live? → Dove abiti? / Dove abita? | Use abita for formal Lei.                                         |
| **E16 · Translate to English**    | 1\. Mi sveglio alle sette. → I wake up at seven. / 2. Non ho più fame. → I'm not hungry anymore. / 3. Ci sono molti turisti. → There are many tourists. / 4. Posso pagare con la carta? → Can I pay by card? / 5. Mio fratello è alto. → My brother is tall.                                                                       |                                                                   |
