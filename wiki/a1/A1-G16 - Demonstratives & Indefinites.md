# A1-G16 — Demonstratives & Indefinites

> Level **A1** · grammar

> [!tip] Quick explanation (English)
> Questo (this) behaves like a normal -o adjective: questo, questa, questi, queste (quest' before a vowel). Quello (that) before a noun changes like the definite article: quel, quello, quell', quella, quei, quegli, quelle. Indefinites: qualche + singular noun (some), alcuni/alcune + plural, ogni + singular (every), tutto il/la (all the), molto, poco, troppo agree like adjectives.

> [!note] شرح سريع (عربي)
> questo (هذا) يتصرف كصفة عادية: questo, questa, questi, queste (و quest' قبل المتحرك). quello (ذلك) قبل الاسم يتغير مثل أداة التعريف: quel, quello, quell', quella, quei, quegli, quelle. النكرات: qualche + مفرد (بعض)، alcuni/alcune + جمع، ogni + مفرد (كل)، tutto il/la (كل الـ)، و molto, poco, troppo تطابق الاسم كالصفات.

### الإشارة والتعريف النكرة: questo, quello, qualche, ogni

*«هذا، ذاك، بعض، كل» — كلمات صغيرة تستعملها في كل جملة. الإيطالية تفرّق في «ذلك» بين القريب من المخاطَب والبعيد — دقة لا توجد في العربية.*

#### questo — هذا/هذه

يتصرف كالصفة العادية:

|  | مفرد | جمع |
|---|---|---|
| مذكر | questo libro / quest'amico | questi libri |
| مؤنث | questa casa / quest'amica | queste case |

#### quello — ذاك/ذلك — يتبع أدوات التعريف!

قبل الاسم يتغير مثل il/lo/la تماما:

| قبل | الصيغة | مثال |
|---|---|---|
| il → | quel | quel libro |
| lo → | quello | quello studente |
| l' → | quell' | quell'amico |
| la → | quella | quella casa |
| i → | quei | quei libri |
| gli → | quegli | quegli studenti |
| le → | quelle | quelle case |

لا تجمع quel مع أداة تعريف: nel quel libro خطأ، الصحيح in quel libro.

#### النكرات — qualche, ogni, alcuni, tutto

| الكلمة | المعنى | ملاحظة |
|---|---|---|
| qualche + مفرد | بعض/بضع | qualche volta — أحيانا |
| alcuni/alcune | بعض (جمع) | alcuni amici |
| ogni + مفرد | كل | ogni giorno — كل يوم |
| tutto/tutti | كل/جميع | tutto il giorno — طوال اليوم |
| molto/molti | كثير | molti amici |
| poco/pochi | قليل | pochi soldi — مال قليل |
| troppo | أكثر من اللازم | troppo caro — غال جدا |
| nessuno | لا أحد / ولا واحد | Non c'è nessuno. — لا يوجد أحد. |

قاعدة qualche: اسم مفرد دائما رغم معنى الجمع — qualche amico وليس amici.

> [!warning] Corrections to the source (تصحيحات)
> - nessuno = nobody / not one; 'nothing' is niente/nulla.
> - 🇸🇦 nessuno = لا أحد / ولا واحد؛ أما «لا شيء» فهي niente / nulla.
