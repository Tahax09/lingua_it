# B2-G04 — Subjunctive Triggers — Complete List

> Level **B2** · grammar

## Subjunctive triggers — complete list
<!-- src: B2 Part 1 · 1.5 -->

| **Category**          | **Expressions**                                                                                                                                                             | **Esempio**                       |
|-----------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------|
| **Opinion**           | penso / credo / ritengo / sostengo / immagino / suppongo che                                                                                                                | Ritengo che sia necessario.       |
| **Wish**              | vorrei / voglio / preferisco / desidero / mi auguro / spero che                                                                                                             | Vorrei che venissi.               |
| **Doubt**             | dubito / non credo / non penso / non sono sicuro / ho dei dubbi che                                                                                                         | Non sono sicuro che abbia capito. |
| **Impersonal**        | è possibile / probabile / importante / necessario / meglio / strano che · bisogna / occorre / serve che                                                                     | Serve che sappiate la verità.     |
| **Formal / elevated** | è opportuno / auspicabile / imprescindibile / doveroso / lecito ritenere che · sarebbe meglio / opportuno / auspicabile che · ritengo necessario che                        | È auspicabile che venga risolto.  |
| **Conjunctions**      | prima che · affinché · perché (= so that) · in modo che · a meno che (non) · purché · a patto che · a condizione che · salvo che · benché · sebbene · nonostante · malgrado | Verrò, a meno che non piova.      |

*Corrections: «È stato dimostrato che le emissioni abbiano raggiunto…» (sentence bank) — dimostrare states a fact → indicative: «hanno raggiunto». «Condivido pienamente» etc. take no subjunctive. «Perché» = because → indicative; = so that → subjunctive. «Sarei grato se potesse venire» is correct (se + imperfetto subjunctive).*

بالعربية: يُستعمل congiuntivo بعد الرأي والرغبة والشك والتعابير غير الشخصية وعبارات الرسمية (è opportuno che…) وبعد: prima che, affinché, a meno che, purché, a patto che, benché, sebbene.
