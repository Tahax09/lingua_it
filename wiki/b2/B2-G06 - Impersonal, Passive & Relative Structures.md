# B2-G06 — Impersonal, Passive & Relative Structures

> Level **B2** · grammar

## Impersonal, passive and relative structures
<!-- src: B2 Part 1 · 1.6 -->

| **Pattern**                       | **Esempio**                          | **English**                            |
|-----------------------------------|--------------------------------------|----------------------------------------|
| Si + 3rd person (impersonal)      | Si pensa che sia necessario.         | It is thought that it is necessary.    |
| Si passivante (singular / plural) | Si dicono molte cose.                | Many things are said.                  |
| Essere + participio               | È stato detto che…                   | It was said that…                      |
| Venire + participio               | Viene considerato che abbia ragione. | He is considered to be right.          |
| Andare + participio (obligation)  | Va ricordato che…                    | It must be remembered that…            |
| Bisogna / occorre / serve che     | Bisogna che tu venga.                | You need to come.                      |
| il che (whole clause)             | Ha fatto tutto, il che mi sorprende. | He did everything, which surprises me. |
| ciò che / quello che              | Ciò che mi preoccupa è…              | What worries me is…                    |

بالعربية: المبني للمجهول بأشكال: essere + اسم المفعول، venire + اسم المفعول، andare + اسم المفعول (للوجوب: Va ricordato = يجب أن يُذكر)، وsi passivante.

## Impersonal and passive
<!-- src: B2 Part 4 · B2+.5 -->

| **Pattern**                           | **Esempio**                                       |
|---------------------------------------|---------------------------------------------------|
| si impersonale + singular verb        | Si mangia bene qui.                               |
| si + plural object (passivante)       | Si vendono case.                                  |
| si è + plural adjective               | Quando si è stanchi, si lavora male.              |
| Compound tense: si è + participle     | Si è lavorato molto. · Si sono viste cose strane. |
| essere / venire / andare + participle | è fatto · viene fatto · va fatto                  |
| Reflexive + si: ci si                 | Ci si diverte.                                    |
