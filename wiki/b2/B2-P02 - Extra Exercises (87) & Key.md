# B2-P02 — Extra Exercises (87) & Key

> Level **B2** · practice

Cover the answers and try each set aloud. 16 sets, 87 items.

| **Set**                                   | **Question → answer**                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | **Rule**                                                                                        |
|-------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------|
| **E1 · Tense sequence (concordanza)**     | 1\. Penso che lui (partire) \_\_\_ ieri. → sia partito / 2. Pensavo che lui (partire) \_\_\_ il giorno prima. → fosse partito / 3. Credo che loro (arrivare) \_\_\_ domani. → arrivino / 4. Credevo che tu (essere) \_\_\_ a casa. → fossi / 5. Vorrei che tu (capire) \_\_\_ ora. → capissi / 6. Avrei voluto che tu (capire) \_\_\_ prima. → avessi capito                                                                                                                                       | Present main → present / passato. Past or conditional main → imperfetto / trapassato.           |
| **E2 · Subjunctive after expressions**    | 1\. È ora che tu (smettere) \_\_\_. → smetta / 2. Bisogna che noi (partire) \_\_\_. → partiamo / 3. Pare che (nevicare) \_\_\_. → nevichi / 4. Peccato che lui non (potere) \_\_\_ venire. → possa / 5. Mi stupisce che lei (dire) \_\_\_ così. → dica / 6. Temo che non (esserci) \_\_\_ posti. → ci siano                                                                                                                                                                                        | Necessity, evaluation, emotion → subjunctive.                                                   |
| **E3 · Concessive & purpose**             | 1\. Nonostante lui (essere) \_\_\_ stanco, ha lavorato. → sia / è (nonostante: subj. formal, indicative spoken) / 2. Benché (fare) \_\_\_ freddo, usciamo. → faccia / 3. Ti scrivo affinché tu (sapere) \_\_\_. → sappia / 4. Esco prima che (piovere) \_\_\_. → piova / 5. Vengo, a patto che tu (guidare) \_\_\_. → guidi / 6. Qualunque cosa (dire) \_\_\_, non ti credo. → dica                                                                                                                | nonostante + subj. (formal) or indicative (spoken).                                             |
| **E4 · Hypotheticals, mixed**             | 1\. Se (io, studiare) \_\_\_ di più, ora sarei laureato. → avessi studiato / 2. Se (tu, dirmelo) \_\_\_, ti avrei aiutato. → me l'avessi detto / 3. Se (io, essere) \_\_\_ in te, accetterei. → fossi / 4. Se avesse piovuto, (noi, rimanere) \_\_\_ a casa. → saremmo rimasti / 5. Se non (tu, arrivare) \_\_\_ in ritardo, avremmo visto il film. → fossi arrivato / 6. (Io, comprare) \_\_\_ la casa, se avessi i soldi. → Comprerei                                                            | Mixed: trapassato subj. + conditional present = past cause, present result.                     |
| **E5 · Come se / senza che / a meno che** | 1\. Parla come se (sapere) \_\_\_ tutto. → sapesse / 2. È partito senza che nessuno (accorgersi) \_\_\_. → se ne accorgesse / 3. Vengo, a meno che non (piovere) \_\_\_. → piova / 4. Si comporta come se non (succedere) \_\_\_ niente. → fosse successo / 5. Lo farò purché tu (aiutare) \_\_\_ me. → aiuti                                                                                                                                                                                      | come se → imperfetto / trapassato.                                                              |
| **E6 · Pronouns combined**                | 1\. Dai il libro a me. → \_\_\_ dai. → Me lo / 2. Ho dato la penna a Marco. → \_\_\_ ho data. → Gliel' / 3. Mandiamo le foto a voi. → \_\_\_ mandiamo. → Ve le / 4. Vuoi dirmi la verità? → Vuoi \_\_\_ ? → dirmela / 5. Compro i fiori per lei. → \_\_\_ compro. → Glieli / 6. Hai dato il regalo a loro? → \_\_\_ hai dato? → Gliel'                                                                                                                                                             | mi→me, ti→te, gli/le→glie- + lo/la/li/le/ne. Participle agrees with a preceding direct pronoun. |
| **E7 · ne / ci**                          | 1\. Hai fratelli? — Sì, (ne / ci) \_\_\_ ho due. → ne / 2. Vai a Roma? — Sì, (ne / ci) \_\_\_ vado domani. → ci / 3. Parli del film? — Sì, (ne / ci) \_\_\_ parlo. → ne / 4. Pensi al futuro? — Sì, (ne / ci) \_\_\_ penso. → ci / 5. Quanti ne vuoi? → \_\_\_ voglio tre. → Ne                                                                                                                                                                                                                    | ne = of it / of them / quantity · ci = there / about it.                                        |
| **E8 · Passive & impersonal**             | 1\. Il ponte (costruire, passato) \_\_\_ nel 1990. → è stato costruito / 2. In Italia (mangiare, si) \_\_\_ molta pasta. → si mangia / 3. Non si (potere) \_\_\_ fumare qui. → può / 4. Quando si è stanchi, (si, essere) \_\_\_ nervosi. → si è / 5. I lavori vanno (finire) \_\_\_ entro lunedì. → finiti                                                                                                                                                                                        | si + 3rd person; si è + plural adjective.                                                       |
| **E9 · Passato remoto**                   | 1\. Dante (nascere) \_\_\_ nel 1265. → nacque / 2. Cesare (vincere) \_\_\_ in Gallia. → vinse / 3. Loro (andare) \_\_\_ a Roma nel 1500. → andarono / 4. Io (fare) \_\_\_ il viaggio nel 1999 (literary). → feci / 5. Lui (dire) \_\_\_ la verità. → disse                                                                                                                                                                                                                                         | Recognise for reading and exams; spoken: passato prossimo.                                      |
| **E10 · Connectors**                      | 1\. \_\_\_ (However) è difficile, ce la farò. → Tuttavia / Comunque / 2. \_\_\_ (Therefore) devo partire. → Quindi / Perciò / 3. \_\_\_ (In fact) hai ragione. → Infatti / 4. \_\_\_ (Moreover) è anche utile. → Inoltre / Per di più / 5. \_\_\_ (On the other hand) costa molto. → D'altra parte / 6. \_\_\_ (In conclusion) possiamo dire… → In conclusione / Insomma                                                                                                                           |                                                                                                 |
| **E11 · Register: informal → formal**     | 1\. Ti scrivo per chiederti informazioni. → La contatto per chiederLe informazioni. / 2. Dimmi quando puoi. → Mi faccia sapere quando può. / 3. Ci vediamo domani? → Possiamo vederci domani? / 4. Fammi sapere. → Mi faccia sapere, per cortesia. / 5. Grazie mille, sei gentile! → La ringrazio, è molto gentile.                                                                                                                                                                                | tu → Lei, use of the conditional for politeness.                                                |
| **E12 · Nominalisation**                  | 1\. Dato che è arrivato, … → Con il suo \_\_\_ , … → arrivo / 2. Quando ha finito → Alla \_\_\_ → fine / conclusione / 3. Se studi → Con lo \_\_\_ → studio / 4. Mentre viaggiavo → Durante il \_\_\_ → viaggio                                                                                                                                                                                                                                                                                    | Formal writing prefers nouns.                                                                   |
| **E13 · Idiomatic / colloquial**          | 1\. Non ce la faccio più. = → I can't take it anymore. / 2. In bocca al lupo! → reply: → Crepi! / 3. Che figata! = → How cool! (informal) / 4. Mi fa piacere = → I'm glad. / 5. Figurati! means: → Don't mention it / No problem.                                                                                                                                                                                                                                                                  |                                                                                                 |
| **E14 · Error hunt**                      | 1\. Se sarei ricco, comprerei. → Se fossi ricco, comprerei. / 2. Penso che tu hai ragione. → Penso che tu abbia ragione. / 3. Benché è tardi, resto. → Benché sia tardi, resto. / 4. Mi ha detto che viene domani. (past) → Mi ha detto che sarebbe venuto il giorno dopo. / 5. Gli ho detto a Maria. → Ho detto a Maria / Le ho detto. / 6. Il film che ti ho parlato. → Il film di cui ti ho parlato.                                                                                            |                                                                                                 |
| **E15 · Translate to Italian**            | 1\. I wish I had studied more. → Vorrei aver studiato di più. / Magari avessi studiato di più. / 2. If it had rained, we would have stayed home. → Se fosse piovuto, saremmo rimasti a casa. / 3. It is important that everyone participate. → È importante che tutti partecipino. / 4. He speaks as if he knew everything. → Parla come se sapesse tutto. / 5. Despite being tired, he went out. → Pur essendo stanco, è uscito. / 6. I'll do it unless it rains. → Lo farò a meno che non piova. |                                                                                                 |
| **E16 · Translate to English**            | 1\. Se solo me l'avessi detto prima! → If only you had told me before! / 2. Si dice che sia il migliore. → They say he is the best. / 3. Non appena avrà finito, ti chiamerà. → As soon as he has finished, he'll call you. / 4. Ciò che conta è partecipare. → What matters is taking part. / 5. Per quanto ci provi, non ci riesce. → However much he tries, he doesn't succeed.                                                                                                                 |                                                                                                 |
