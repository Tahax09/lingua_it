# B2-R01 — One-Page Revision Sheet

> Level **B2** · revision

| **Sequence**     | **Same time / after**  | **Before**             |
|------------------|------------------------|------------------------|
| Present main     | congiuntivo presente   | congiuntivo passato    |
| Past main        | congiuntivo imperfetto | congiuntivo trapassato |
| Conditional main | congiuntivo imperfetto | congiuntivo trapassato |

| **Conditionals** | **Pattern**                           | **Esempio**                         |
|------------------|---------------------------------------|-------------------------------------|
| Type 1           | Se + presente, futuro                 | Se piove, resto.                    |
| Type 2           | Se + imperfetto subj., condizionale   | Se avessi tempo, andrei.            |
| Type 3           | Se + trapassato subj., cond. passato  | Se fossi venuto, avrei visto.       |
| Mixed            | Se + trapassato subj., cond. presente | Se avessi studiato, sarei laureato. |

| **Combined pronouns**                  | **Forms**                                  |
|----------------------------------------|--------------------------------------------|
| mi / ti / ci / vi + lo, la, li, le, ne | me lo · te la · ce li · ve le · me ne      |
| gli / le + lo, la, li, le, ne          | glielo · gliela · glieli · gliele · gliene |

| **Subjunctive triggers**                                                               | **Remember**                            |
|----------------------------------------------------------------------------------------|-----------------------------------------|
| opinion · wish · emotion · doubt · impersonal evaluation                               | different subject → che + subj.         |
| benché · sebbene · nonostante · affinché · purché · a meno che · prima che · senza che | always subj. (nonostante may take ind.) |
| come se · il più… che · l'unico che · qualunque · chiunque                             | subj.                                   |
| so che · è vero che · è certo che · siccome · dato che · poiché · dopo che             | indicative                              |

| **Connectors**                              | **Use**     |
|---------------------------------------------|-------------|
| tuttavia · comunque · eppure                | however     |
| quindi · perciò · pertanto · di conseguenza | therefore   |
| inoltre · per di più                        | moreover    |
| insomma · in conclusione · tutto sommato    | to conclude |

| **Top 6 B2 mistakes**        | **Fix**                      |
|------------------------------|------------------------------|
| Se sarei…                    | Se fossi…                    |
| Penso che hai                | Penso che abbia              |
| Il film che ti ho parlato    | Il film di cui ti ho parlato |
| Gli ho detto a Maria         | Le ho detto                  |
| Mi ha detto che viene (past) | …che sarebbe venuto          |
| Lo ho visto                  | L'ho visto                   |
