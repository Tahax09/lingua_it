# B1-G05 — Periodo Ipotetico — Hypothetical Sentences

> Level **B1** · grammar

## Hypothetical sentences — periodo ipotetico (3 types)
<!-- src: B1 Part 1 · 1.6 -->

| **Type**                | **Structure**                                      | **Esempio**                                                               | **Meaning**              | **العربية** |
|-------------------------|----------------------------------------------------|---------------------------------------------------------------------------|--------------------------|---|
| **1 · Real**            | Se + presente, futuro / presente                   | Se piove, non uscirò.                                                     | Likely or possible       | **١ · حقيقي:** se + مضارع، ثم مستقبل / مضارع ← إن أمطرت لن أخرج. (محتمل أو ممكن) |
| **2 · Unreal present**  | Se + congiuntivo imperfetto, condizionale presente | Se avessi tempo, andrei. · Se fossi ricco, viaggerei di più.              | Unlikely / imaginary now | **٢ · غير حقيقي في الحاضر:** se + congiuntivo imperfetto، ثم شرطي حاضر ← لو كان عندي وقت لذهبتُ. · لو كنتُ غنياً لسافرتُ أكثر. (غير محتمل / متخيّل الآن) |
| **3 · Impossible past** | Se + congiuntivo trapassato, condizionale passato  | Se fossi venuto, avrei visto tutto. · Se avessi studiato, avrei superato. | Cannot change anymore    | **٣ · ماضٍ مستحيل:** se + congiuntivo trapassato، ثم شرطي ماضٍ ← لو كنتَ أتيتَ لرأيتَ كل شيء. · لو درستُ لنجحتُ. (لا يمكن تغييره) |

Type 2 verbs: avessi / fossi / potessi / facessi / andassi / dicessi + condizionale (andrei, sarei, farei). Type 3 verbs: avessi / fossi + participle + avrei / sarei + participle.

🇸🇦 أفعال النوع ٢: avessi / fossi / potessi / facessi / andassi / dicessi + شرطي (andrei، sarei، farei). أفعال النوع ٣: avessi / fossi + اسم المفعول + avrei / sarei + اسم المفعول.

*Corrections to your pack: «Se avevo tempo, andrei» ✗ → «Se avessi tempo, andrei» ✓. «Se fosse ricco» for «io» ✗ → «Se fossi ricco, viaggerei di più» (io fossi / lui fosse). In spoken Italian «Se avevo tempo, venivo» (imperfetto both sides) exists but is colloquial — never mix it with the conditional.*

🇸🇦 *تصحيحات للمصدر: «Se avevo tempo, andrei» ✗ ← «Se avessi tempo, andrei» ✓. و«Se fosse ricco» مع «io» ✗ ← «Se fossi ricco, viaggerei di più» (io fossi / lui fosse). في الكلام العامي توجد «Se avevo tempo, venivo» (imperfetto في الجزأين) لكنها عامية — لا تخلطها أبداً مع الشرطي.*

بالعربية: النوع 1: Se + مضارع، مستقبل. النوع 2 (غير واقعي): Se + imperfetto del congiuntivo، condizionale. النوع 3 (مستحيل في الماضي): Se + trapassato del congiuntivo، condizionale passato.

## Periodo ipotetico — all combinations
<!-- src: B1 Part 4 · B1+.3 -->

| **Type**                  | **If-clause**               | **Result**                     | **Esempio**                                    | **العربية** |
|---------------------------|-----------------------------|--------------------------------|------------------------------------------------|---|
| Real / habitual           | Se + presente               | presente / futuro / imperativo | Se piove, resto a casa. · Se hai fame, mangia! | حقيقي / معتاد: se + مضارع ← مضارع / مستقبل / أمر: إن أمطرت أبقى في البيت. · إن كنتَ جائعاً فكُل! |
| Real, future              | Se + futuro                 | futuro                         | Se avrò tempo, verrò.                          | حقيقي في المستقبل: se + مستقبل ← مستقبل: إن كان عندي وقت سآتي. |
| Possible / unreal present | Se + imperfetto congiuntivo | condizionale presente          | Se avessi tempo, viaggerei.                    | ممكن / غير حقيقي في الحاضر: se + congiuntivo imperfetto ← شرطي حاضر: لو كان عندي وقت لسافرتُ. |
| Impossible past           | Se + trapassato congiuntivo | condizionale passato           | Se avessi studiato, avrei passato.             | ماضٍ مستحيل: se + congiuntivo trapassato ← شرطي ماضٍ: لو درستُ لنجحتُ. |
| Mixed                     | Se + trapassato congiuntivo | condizionale presente          | Se avessi studiato, ora sarei laureato.        | مختلط: se + congiuntivo trapassato ← شرطي حاضر: لو درستُ لكنتُ الآن متخرّجاً. |

*Never put the conditional after «se»: Se avessi tempo, andrei ✓ — Se andrei ✗. In very colloquial speech Italians say «Se avevo tempo, venivo» (imperfetto both sides) but avoid it in writing.*

🇸🇦 *لا تضع الشرطي أبداً بعد «se»: Se avessi tempo, andrei ✓ — Se andrei ✗. في الكلام العامي جداً يقول الإيطاليون «Se avevo tempo, venivo» لكن تجنّبها في الكتابة.*

## 🇸🇦 Arabic lesson — If-clauses (periodo ipotetico)
<!-- src: Arabic Lessons · L23 -->

### الجمل الشرطية مع se: لو... إذا...

*«لو كان عندي مال لسافرت» — الشرطية الإيطالية لها ثلاث درجات: محتمل، غير محتمل في الحاضر، ومستحيل في الماضي. مثل العربية تماما في الفكرة.*

#### النوع الأول — شرط حقيقي (se + indicativo)

شيء ممكن: se + مضارع/مستقبل → مضارع/مستقبل:

- Se piove, resto a casa. — إن مطرت، أبقى في البيت.
- Se studi, passerai l'esame. — إن درست، ستنجح.
- Se hai fame, mangia! — إن كنت جائعا، كُل!

#### النوع الثاني — شرط متخيل (se + congiuntivo imperfetto → condizionale)

خيال في الحاضر — مثل «لو كنتَ غنيا لاشتريت»:

- Se fossi ricco, comprerei una villa. — لو كنت غنيا، لاشتريت فيلا.
- Se avessi tempo, verrei con te. — لو كان عندي وقت، لجئت معك.
- Se parlassi italiano, troverei lavoro. — لو تكلمت الإيطالية، لوجدت عملا.
- قاعدة صارمة: بعد se للتخيل لا نقول condizionale — خطأ شائع حتى بين الإيطاليين: ❌ se sarei

#### النوع الثالث — ندم على الماضي

شيء فات وانتهى: se + congiuntivo trapassato → condizionale passato:

- Se avessi studiato, avrei passato l'esame. — لو درست، لكنت نجحت.
- Se fossi partito presto, non avrei perso il treno. — لو انطلقت مبكرا، لما فاتني القطار.
- الأصعب لكنه الأكثر أهمية للفهم — الإيطاليون يستعملونه كثيرا في القصص والندم.
