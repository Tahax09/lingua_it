# B1-P02 — Extra Exercises (118) & Key

> Level **B1** · practice

Cover the answers and try each set aloud. 21 sets, 118 items. The last column gives the rule.

| **Set**                                | **Question → answer**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | **Rule**                                                                                                |
|----------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------|
| **E1 · Regular subjunctive**           | 1\. Penso che tu (parlare) \_\_\_ bene. → parli / 2. Credo che lei (scrivere) \_\_\_ molto. → scriva / 3. Spero che voi (capire) \_\_\_. → capiate / 4. È importante che noi (partire) \_\_\_ presto. → partiamo / 5. Voglio che loro (finire) \_\_\_. → finiscano / 6. Dubito che tu (dormire) \_\_\_ abbastanza. → dorma                                                                                                                                                                             | capire/finire: -isc- in io/tu/lui/loro → finiscano.                                                     |
| **E2 · Irregular subjunctive**         | 1\. Penso che io (essere) \_\_\_ stanco. → sia / 2. Credo che tu (avere) \_\_\_ ragione. → abbia / 3. Spero che lui (andare) \_\_\_ bene. → vada / 4. Voglio che voi (fare) \_\_\_ silenzio. → facciate / 5. Dubito che lei (sapere) \_\_\_ la verità. → sappia / 6. È possibile che loro (potere) \_\_\_ venire. → possano / 7. Preferisco che lui (stare) \_\_\_ qui. → stia / 8. Penso che noi (dovere) \_\_\_ partire. → dobbiamo                                                                  | noi form = indicative (dobbiamo).                                                                       |
| **E3 · Indicative or subjunctive?**    | 1\. So che tu (sei / sia) \_\_\_ bravo. → sei / 2. Penso che (è / sia) \_\_\_ tardi. → sia / 3. È certo che (viene / venga) \_\_\_. → viene / 4. Non credo che (ha / abbia) \_\_\_ ragione. → abbia / 5. È vero che (è / sia) \_\_\_ difficile. → è / 6. Mi sembra che (è / sia) \_\_\_ giusto. → sia / 7. Sono sicuro che (arriva / arrivi) \_\_\_. → arriva / 8. Dubito che (è / sia) \_\_\_ vero. → sia                                                                                             | Certainty (so, è certo, è vero, sono sicuro) → indicative.                                              |
| **E4 · Same subject: di + infinitive** | 1\. Spero che io passi l'esame. → → Spero di passare l'esame. / 2. Credo che io abbia ragione. → → Credo di avere ragione. / 3. Dubito che io riesca a finire. → → Dubito di riuscire a finire. / 4. Sono contento che io sia qui. → → Sono contento di essere qui. / 5. Penso che tu parli bene. → (different subject) → No change: subject changes → che + subjunctive                                                                                                                               | Same subject → di + infinitive.                                                                         |
| **E5 · Imperfect subjunctive**         | 1\. Se io (avere) \_\_\_ tempo, viaggerei. → avessi / 2. Vorrei che tu (venire) \_\_\_. → venissi / 3. Pensavo che lui (essere) \_\_\_ qui. → fosse / 4. Credevo che noi (fare) \_\_\_ bene. → facessimo / 5. Sarebbe meglio che voi (partire) \_\_\_. → partiste / 6. Se loro (potere) \_\_\_, verrebbero. → potessero                                                                                                                                                                                | Forms in B1 §1.8 / B2 §1.3.                                                                                   |
| **E6 · Pluperfect subjunctive**        | 1\. Se io (studiare) \_\_\_ di più, avrei passato. → avessi studiato / 2. Credevo che tu (partire) \_\_\_ già. → fossi partito / 3. Avrei voluto che lui (venire) \_\_\_. → fosse venuto / 4. Se noi (arrivare) \_\_\_ prima, avremmo visto. → fossimo arrivati / 5. Pensavo che loro (finire) \_\_\_. → avessero finito                                                                                                                                                                               | avessi/fossi + participle.                                                                              |
| **E7 · Which tense?**                  | 1\. Penso che lui (essere) \_\_\_ qui ora. → sia / 2. Penso che lui (essere) \_\_\_ qui ieri. → sia stato / 3. Pensavo che lui (essere) \_\_\_ qui. → fosse / 4. Pensavo che lui (essere) \_\_\_ qui prima. → fosse stato / 5. Vorrei che tu (venire) \_\_\_ ieri. → fossi venuto                                                                                                                                                                                                                      | Main verb present → present/passato. Past or conditional → imperfetto/trapassato.                       |
| **E8 · Conditionals**                  | 1\. Se piove, (io, restare) \_\_\_ a casa. → resterò / 2. Se (io, avere) \_\_\_ tempo, ti aiuterò. → ho / 3. Se (io, avere) \_\_\_ soldi, comprerei una casa. → avessi / 4. Se (tu, essere) \_\_\_ qui, saremmo felici. → fossi / 5. Se (io, sapere) \_\_\_, ti avrei detto. → avessi saputo / 6. Se (noi, partire) \_\_\_ prima, saremmo arrivati. → fossimo partiti / 7. Se (lui, studiare) \_\_\_, supererebbe l'esame. → studiasse / 8. Se (tu, venire) \_\_\_ ieri, avresti visto. → fossi venuto | Type 1: present + future. Type 2: imperfetto subj + conditional. Type 3: trapassato + past conditional. |
| **E9 · Conjunctions**                  | 1\. (Benché / Siccome) \_\_\_ sia tardi, resto. → Benché / 2. (Siccome / Affinché) \_\_\_ è tardi, vado. → Siccome / 3. Studio (affinché / dato che) \_\_\_ tu capisca. → affinché / 4. (Dato che / Purché) \_\_\_ non hai tempo, faccio io. → Dato che / 5. Ti aiuto (purché / poiché) \_\_\_ tu studi. → purché / 6. \_\_\_ piove, esco. (Anche se / Sebbene) → Anche se                                                                                                                             | Subjunctive: benché, affinché, purché, sebbene. Indicative: siccome, dato che, poiché, anche se (real). |
| **E10 · Trapassato prossimo**          | 1\. Quando sono arrivato, il film (iniziare) \_\_\_ già. → era iniziato / 2. (Io, mangiare) \_\_\_ già quando mi hai chiamato. → Avevo mangiato / 3. Non (io, vedere) \_\_\_ mai Roma prima. → avevo mai visto / 4. Lei (uscire) \_\_\_ già quando ho telefonato. → era già uscita / 5. Noi (finire) \_\_\_ prima che lui arrivasse. → avevamo finito                                                                                                                                                  | avevo/ero + participle = the earlier past.                                                              |
| **E11 · Condizionale passato**         | 1\. (Io, volere) \_\_\_ venire, ma ero occupato. → Avrei voluto / 2. (Tu, dovere) \_\_\_ aspettare. → Avresti dovuto / 3. (Noi, andare) \_\_\_ al mare. → Saremmo andati / 4. (Lui, arrivare) \_\_\_ prima. → Sarebbe arrivato / 5. (Voi, fare) \_\_\_ lo stesso? → Avreste fatto                                                                                                                                                                                                                      | avrei / sarei + participle: regret, unreal past.                                                        |
| **E12 · Futuro anteriore**             | 1\. Quando (io, finire) \_\_\_, ti chiamerò. → avrò finito / 2. Appena (lui, arrivare) \_\_\_, partiremo. → sarà arrivato / 3. Dov'è Marco? — (Uscire) \_\_\_ già. → Sarà uscito / 4. Dopo che (noi, mangiare) \_\_\_, usciremo. → avremo mangiato                                                                                                                                                                                                                                                     | Future auxiliary + participle: finished before another future event; or a guess about the past.         |
| **E13 · Relative pronouns**            | 1\. Il libro \_\_\_ leggo è bello. → che / 2. La città \_\_\_ vivo è piccola. → in cui / 3. Il ragazzo di \_\_\_ parlo è italiano. → cui / 4. \_\_\_ studia impara. → Chi / 5. \_\_\_ dici è vero. → Quello che / Ciò che / 6. L'amico con \_\_\_ esco è simpatico. → cui                                                                                                                                                                                                                              | che = who/which/that (no preposition). Preposition + cui.                                               |
| **E14 · Passive**                      | 1\. Dante ha scritto la Divina Commedia. → → La Divina Commedia è stata scritta da Dante. / 2. Tutti conoscono il museo. → → Il museo è conosciuto da tutti. / 3. Il libro (leggere, futuro) \_\_\_ da molti. → sarà letto / 4. Il pane (vendere, si passivante) \_\_\_ qui. → si vende / 5. Le case (costruire, venire) \_\_\_ ogni anno. → vengono costruite                                                                                                                                         | essere / venire + participle (agrees with the subject).                                                 |
| **E15 · Gerund**                       | 1\. Sto (mangiare) \_\_\_. → mangiando / 2. (Studiare) \_\_\_ ogni giorno, si impara. → Studiando / 3. Stavo (leggere) \_\_\_ quando sei arrivato. → leggendo / 4. (Essere) \_\_\_ stanco, sono andato a letto. → Essendo                                                                                                                                                                                                                                                                              | -ando (-are) · -endo (-ere / -ire); essere → essendo, fare → facendo, dire → dicendo.                   |
| **E16 · Imperative**                   | 1\. (tu, dire) \_\_\_ la verità! → Di' / 2. (Lei, venire) \_\_\_ qui, per favore. → Venga / 3. (tu, non fumare) \_\_\_! → Non fumare / 4. (tu, fare + mi) \_\_\_ un favore. → Fammi / 5. (Lei, sedersi) \_\_\_ pure. → Si accomodi / Si sieda                                                                                                                                                                                                                                                          | Irregular tu: di', fa', da', va', sta'. | **E17 · Indirect speech**              | 1\. | **E18 · Formal register**              | 1\. Puoi aiutarmi? → → Può aiutarmi? / Potrebbe aiutarmi? / 2. Ti ringrazio per la tua email. → → La ringrazio per la Sua email. / 3.
